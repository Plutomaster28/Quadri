# SeaBird SDK v1.0.0 — Advanced Processor Edition

Release date: 2026-08-14  
Standard-build tag: `marlin`  
Parent architecture: SeaBird 3.2

Version 1.0 freezes the general and advanced-processor architecture surface.
It includes 325 normative instructions, ten performance markers, PAE32,
register windowing, the SB32/SB64 ABIs, the Axium M v1 target profile, and the
existing Tritium embedded subset.

Highlights:

- PAE32 retains ILP32 and expands translated physical addresses to 36 bits.
- The opt-in windowed ABI provides eight overlapping integer argument
  registers with transparent hardware spill/restore.
- LLVM/Clang understand `axium-m-v1`, its feature macros, ABI register maps,
  feature-gated instructions, and ELF compatibility flags.
- Every normative instruction has a generated MC record and golden vector.
- Independent PAE, arithmetic, FP, vector, crypto, memory-model, C ABI, ELF,
  example-program, translator, and reference-model tests are included.

See `docs/PAE32_EXTENSION.md`, `docs/REGISTER_WINDOWING_EXTENSION.md`, and
`docs/V1_0_RATIFICATION_REPORT.md` for the frozen contracts and evidence.

The architecture sources and Linux x86_64 compiler package are qualified. The
compiler bundle was rebuilt from LLVM 22.1.4 commit
`35990504507d79e0b9deb809c8ee5e1b34ceef20` with assertions enabled; the native
backend integration suite and regenerated PDF documentation pass. Exact build
identity and tool hashes are included in the packaged provenance record.
