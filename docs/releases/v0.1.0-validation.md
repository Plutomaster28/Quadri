# SeaBird SDK v0.1.0 Validation Record

Validation date: 2026-07-21  
Validated package: `seabird-sdk-v0.1.0-tuna-linux-x86_64.zip`

## Release gates

- [x] SDK version and architecture version are explicitly separated.
- [x] The official standard-build identity is recorded as tag `tuna`.
- [x] The source and SDK carry the Apache License 2.0 text.
- [x] LLVM/Clang SeaBird targets build successfully.
- [x] All 310 normative golden vectors and 34 edge vectors pass.
- [x] The complete reference-model C/link/runtime conformance suite passes.
- [x] Binary128 arithmetic, calls, 16-byte stack overflow arguments,
  comparisons, conversions, assembly round-trip, and execution pass.
- [x] Symbol inspection, static archives, archive indexing, raw object-section
  extraction, Intel HEX conversion, and stripping pass on SeaBird ELF.
- [x] The SDK ZIP contains an internal SHA-256 manifest and external archive
  checksum.
- [x] The SDK was unpacked outside the source tree; its packaged Clang compiled
  `examples/c-smoke.c`, and its packaged reader/disassembler recognized the
  resulting `elf64-seabird` object and instructions.
- [x] The packaged static linker emitted both loadable ELF64 and non-empty flat
  binary images from the packaged example.

## Commands represented by the validation

```sh
python3 tools/run_conformance.py
python3 tools/package_sdk.py --llvm-build /tmp/llvm-build-seabird
sha256sum -c MANIFEST.sha256
bin/clang --target=seabird64-unknown-none -O2 -ffreestanding \
  -fno-builtin -c examples/c-smoke.c -o c-smoke.o
bin/llvm-readobj --file-headers --symbols c-smoke.o
bin/llvm-objdump -d c-smoke.o
python3 bin/link_seabird.py --format elf --entry seabird_mix \
  -o c-smoke.elf c-smoke.o
python3 bin/link_seabird.py --format binary -o c-smoke.bin c-smoke.o
```
